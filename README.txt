Programming Language: Python

How to Run:

Server Side:
    Run: python3 serv.py [server port number]

Client Side:
    Run: python3 cli.py localhost [server port number]

    Enter commands:
        ls - View all files in serverFiles directory
        get [filename] - download a file from serverFiles directory
        put [filename] - upload file from clientFiles to serverFiles
        quit - close the server and client connections
